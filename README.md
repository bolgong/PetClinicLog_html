## 发布

GitHub Pages 从 `main` 分支根目录发布，无构建依赖。修改 HTML 和本地 `styles.css` 后提交即可更新。

页面采用系统字体，支持移动设备、深色模式与打印，无 JavaScript、分析脚本或第三方资源。参考 mystic-latam-legal 的独立静态页面结构，内容按 PetClinicLog 当前实现重新编写。

## 内容维护

当前版本无需账号、未提供应用内云同步、广告 SDK、AI 或应用内订阅。新增这些能力或改变信息处理方式时，应同步更新政策、用户提示及商店披露。系统备份、主动分享和 GitHub Pages 访问日志在隐私政策中分别说明。

联系渠道为本仓库公开 Issues；请勿在公开问题中提交个人或敏感信息。
