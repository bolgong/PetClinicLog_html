隐私政策

更新及生效日期：2026 年 9 月 9 日

本政策适用于由 GitHub 账号 bolgong 维护的「宠物病历助手」（PetClinicLog，以下简称“本应用”）及其隐私政策、用户协议网页，说明信息的处理方式及你的选择。

当前版本的核心功能在本机运行，无需注册账号。宠物档案、健康记录与所选照片保存在应用的本地存储中；我们未提供业务服务器上传或应用内云同步功能，也未接入广告、第三方行为分析或 AI 服务。

一、应用在本机处理哪些信息

  • 宠物档案：你填写的宠物名字、物种、品种、年龄、体重、诊断与处方粮，用于管理和区分宠物。
  • 健康记录：你填写的呕吐、排便、用药或症状记录，包括发生时间、程度、详情与备注，用于历史查看、统计与报告生成。
  • 照片：你主动选择添加的照片，用于记录展示及 PDF 报告。照片或备注可能包含人物、联系方式等信息，请只添加你有权处理且确有必要的内容。
  • 本地状态：宠物和记录的本地标识、当前选中的宠物等，用于关联记录及恢复界面状态，不用于跨应用跟踪。

本应用不要求提供你的姓名、手机号、电子邮箱或账户密码，不读取通讯录、精确位置、麦克风或 Apple 健康数据，也不主动向开发者发送上述本地内容。

二、照片选择与系统权限

添加照片时使用 Apple 的系统照片选择器，仅将你选中的照片导入本应用，不主动扫描整个照片库。你可以取消选择，继续使用文字记录功能。当前版本未启用应用内拍照功能。

你可以在系统设置中管理本应用可用的权限。撤回访问权限不会自动删除此前已导入的照片；如需删除，请在应用内编辑相应记录，或删除对应宠物及关联记录。保存在系统相册中的原始照片不受应用内删除操作影响。

三、本机存储、系统备份与保留期限

档案与记录保存在本机数据库，导入的照片保存在应用沙盒。数据一般保留至你删除相关内容或删除应用及其数据。本应用未提供自主的云同步或服务器备份；如果你启用了 iCloud 设备备份、电脑备份或设备迁移，操作系统可能将应用数据纳入其中，其处理受你的系统设置及 Apple 的规则约束。

PDF 导出文件暂存在应用临时目录，可能被系统清理。删除原始记录或宠物不会自动删除已经生成的 PDF、你另存的文件、第三方收到的副本或系统备份。这些副本需要在相应位置单独管理。

四、导出、分享与第三方服务

PDF 报告在本机生成。只有当你主动使用系统分享功能并选择接收方或保存位置时，相关文件才会交由你选择的应用或服务处理。分享前请检查报告内容；接收方的存储、使用和删除规则由其自身政策约束。

我们不出售本地记录，不将其用于广告画像，也不主动提供给第三方。Apple 可能依照你的系统设置和其政策处理商店、系统诊断或设备备份信息；这与本应用自行上传宠物记录不同。详情请参阅 Apple 隐私政策。

五、访问本政策网页与联系支持

本政策与用户协议由 GitHub Pages 托管。打开网页需要联网，但不会附带上传应用中的宠物档案或照片。网页本身不设置分析脚本、广告、Cookie 或本地存储，也不加载第三方字体。

GitHub 会为安全目的记录访问者的 IP 地址。访问 GitHub 或提交 Issue 时，GitHub 还会按其政策处理账户和访问相关信息。详情请参阅 GitHub Pages 说明和 GitHub 隐私声明。

如你主动提交支持问题，我们会使用你提交的内容排查问题和回复。GitHub Issues 是公开渠道，请勿上传个人联系方式、完整病历、未脱敏照片或其他敏感内容。

六、你的选择与数据管理

  • 查看与更正：在应用内查看或编辑宠物档案和健康记录。
  • 获取副本：在报告页或记录编辑页导出 PDF，并通过系统分享保存。PDF 为阅读用报告，不能作为应用数据导入恢复。
  • 删除：可通过“我的 → 宠物档案”删除对应宠物及其关联记录和应用内照片。要清除本机应用数据，可在系统设置中选择“删除 App”；“卸载 App”可能保留数据。
  • 管理其他副本：另存文件、已分享文件及系统备份请在对应应用、接收方或备份设置中处理。

由于我们无法远程访问你的本地数据库，不能代你查阅、更改、恢复或删除设备中的记录。涉及你向支持渠道主动提供的信息，可通过下方渠道提出访问、更正或删除请求；我们会在适用法律要求范围内处理，GitHub 平台保留的副本同时受其规则约束。

七、未成年人

本应用并非专门面向儿童提供的服务。未成年人应在监护人指导下使用，避免在备注、照片或公开支持渠道中提交本人或他人的个人信息。监护人如对相关信息有疑问，可联系我们。

八、安全与政策更新

我们依赖 iOS 的应用沙盒与系统安全能力保存本地内容。请妥善管理设备锁屏、备份和分享对象。任何存储或传输方式都无法保证绝对安全。

功能或信息处理方式发生变化时，我们会更新本政策和页面日期。若引入新的上传、账号、分析或其他需取得授权的处理方式，将按适用要求告知并获取必要授权，不以本政策概括授权尚未提供的功能。
